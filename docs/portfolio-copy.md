# Portfolio entry

**VoicePrep — Prepare spoken audio before or during a take.**

A native Mac app and Audio Unit for reducing low rumble, evening out louder speech and controlling sample peaks. Prepare an existing interview/presentation WAV, monitor a microphone locally, or insert the effect in an AUv2 recording host.

C++ · Objective-C++ · AppKit · AVFoundation · Audio Unit · Digital signal processing

Stateful linked-stereo DSP, smoothed live controls, a 5 ms lookahead limiter, aligned file A/B playback and source-preserving 24-bit WAV export. Apple Audio Unit validation and an actual AVAudioEngine host pass locally. Built with Codex assistance.

Not a denoiser or a virtual microphone. Ad-hoc signed, not notarized. Listening preference and broad DAW compatibility still need real user validation.
