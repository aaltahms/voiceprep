# Speech source: Open Speech Repository

The human speech comes from **Open Speech Repository**, developed by Telchemy.

- Recording: https://www.voiptroubleshooter.com/open_speech/american/OSR_us_000_0010_8k.wav
- Repository and conditions: https://www.voiptroubleshooter.com/open_speech/
- American English index: https://www.voiptroubleshooter.com/open_speech/american.html
- Retrieved October 17, 2026.

The repository permits copying, modifying, broadcasting and incorporating these materials, requiring identification of the source as “Open Speech Repository.” These are attribution conditions, not an assertion that the recordings carry the MIT license used for VoicePrep's own code.

`osr-source.wav` is the complete downloaded source recording. `spoken-original.wav` is an 18-second excerpt with deliberately introduced 35 Hz rumble and varying speech gain. `prepare_example.py` reproduces these changes. `provenance.json` records input/output hashes and the recipe. The example contains a human voice with constructed faults; it is not evidence of repairing an uncontrolled real-room recording. The source is 8 kHz telephone-band audio; processing does not restore missing high frequencies.
